# Camera
# pyrealsense2 has prebuilt pip wheels for Windows and Linux x86_64 only — there is
# no macOS wheel at all (Intel dropped official macOS builds) and no Linux aarch64
# wheel (which is what Docker builds on an Apple Silicon Mac or a Jetson). Where the
# wheel is unavailable the app falls back to a placeholder feed (see
# camera_integration.py); for a real camera on Jetson, build librealsense + the
# Python bindings from source instead (see SETUP.md).
pyrealsense2 ; platform_system == "Windows" or (platform_system == "Linux" and platform_machine == "x86_64")
